# thanushthrony.github.io

Source for my portfolio at **[thanushthrony.github.io](https://thanushthrony.github.io/)**.
I'm an M.Sc. Data Science student at FAU Erlangen-Nürnberg working on machine
learning, deep learning and recommender systems.

Plain HTML, CSS and JavaScript, served by GitHub Pages from `main`. No build step.

## Highlights

- **[Live recommender demo](https://thanushthrony.github.io/projects/recommender-demo.html)**:
  the trained two-tower network from my NCECA 2023 paper, running entirely in the
  browser. Code and training pipeline: [movie-recommender](https://github.com/thanushthrony/movie-recommender).
- **[Deep learning guide](https://thanushthrony.github.io/blog/deep-learning-guide.html)**:
  a 16-chapter interactive guide.
- **Interactive architecture diagram** on the home page (`assets/nn-diagram.js`).

## Structure

```
index.html                  Home: about, experience, skills, education, contact
404.html                    Not-found page
assets/                     Stylesheet, network diagram script, photo, CV
blog/                       Blog index and posts
notes/                      Paper reading notes
opensource/                 Open-source contribution log
projects/
  index.html                Projects overview
  recommender-demo.html     In-browser recommender demo
  model-data.js             Trained weights and movie embeddings for the demo,
                            generated by movie-recommender/export_model_for_web.py
```

## Run locally

```bash
python3 -m http.server 8000   # then open http://localhost:8000
```
